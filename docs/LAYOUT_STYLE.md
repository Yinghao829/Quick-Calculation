整体风格：玻璃拟态（Glassmorphism）+ 果冻/亚克力光泽质感，柔和马卡龙低饱和渐变背景，属于偏年轻化的学习工具UI，是Android刷题App的题型选择配置页。

页面文字有部分乱码（图片渲染问题，不看乱码，只描述UI结构、布局、视觉元素）

一、顶部区域（状态栏 + 页面标题）

1.最上方不能与手机原生状态栏重合
页面标题栏：
- 左侧：青蓝色多面体水晶/宝石小图标；
- 主标题文字：选择题型，粗体，深青黑色大号字体；
- 右上角：简化版WiFi、信号、电池图标装饰（和系统状态栏重复，属于页面内装饰元素）
  3.背景：淡薄荷青底色，带有模糊、虚化的浅橙、浅粉圆形柔焦光斑散景，朦胧柔和，低对比度，不抢内容焦点。

二、核心区：题型选择模块（2列网格布局）

采用2×N网格卡片排布，题型卡片是玻璃拟态白底磨砂卡片，带有细淡描边、轻微阴影，圆角矩形卡片，卡片内布局统一：

- 左侧：小圆点标识 + 题型主标题（粗体大字）
- 下方：小字辅助描述文本
- 最右侧：一个勾代表选上，暗示多选

卡片清单：

1.左上卡片（选中态高亮）：「增长量」，卡片使用青→绿渐变玻璃高光边框，视觉突出；副标题一行小字描述。
2.右上卡片：「基期与现期」，默认未选中，磨砂白底玻璃卡片。
3.左第二行：「一般增长率」，白底磨砂卡片。
4.右第二行：「比例」，白底磨砂卡片
5.左第三行：「平均」，白底磨砂卡片。
6.右第三行：「倍数」，白底磨砂卡片。
7.左第四行：「特殊增长率」，白底磨砂卡片。
8.右第四行：速算，白底磨砂卡片。（内容、逻辑待实现）

卡片之间保留充足留白，间距均匀。

三、配置分组区域（难度 / 作答模式 / 主题）

整体包裹在一个大的磨砂玻璃容器内，容器有圆角，半透明白底，和背景虚化融合。
内部分为3组选项，每组包含标题 + 横向单选选项（选项为圆角矩形单选框，右侧带圆形单选按钮）：

1.难度
选项：困难（选中，青高亮边框）、中等、困难（重复，图片渲染错误）
2.作答模式
选项：选择（选中高亮）、填空
3.主题
选项：浅色（选中高亮）、深色（重复，渲染错误）、跟随系统

单选选中态：边框变为青蓝色高亮，内部单选圆圈填充高亮；未选中为浅灰细边框。

四、底部主操作按钮

按钮（大圆角，接近椭圆）

- 视觉效果：类似透明泡泡/水晶，青蓝底色+紫边反光，立体高光，有通透折射质感；
- 居中白色粗大字：开始练习；
- 页面最核心行动入口，视觉权重最高。

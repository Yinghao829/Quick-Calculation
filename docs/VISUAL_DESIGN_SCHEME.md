# 基期与现期 · 练习App 视觉设计方案

> 设计原则：克制、信息优先、统一性、现代感

## 一、设计规范总览

| 项目 | 规范 |
|------|------|
| 圆角 | 卡片 16px / 选项 12px / 按钮 12px |
| 内边距 | 卡片 20px 24px / 页面边距 20px |
| 间距体系 | 卡片间距 16px / 题干与选项 24px / 选项间距 12px |
| 字体 | -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif |
| 数字格式 | 等宽数字（font-variant-numeric: tabular-nums） |
| 交互反馈 | 无弹窗、无位移，仅透明度与边框过渡 |

## 二、浅色主题（Light）

### 背景色板

| 层级 | 颜色值 | 用途 |
|------|--------|------|
| 页面背景 | `#F5F7FA` | 主背景 |
| 卡片背景 | `#FFFFFF` | 题目卡片、选项卡片 |
| 分割线 | `#E9EDF2` | 细分割线 |
| 次级背景 | `#F0F2F5` | 按钮悬停/禁用态 |

### 文字色板

| 用途 | 颜色值 |
|------|--------|
| 主标题（数字、关键数据） | `#1A1D24` |
| 正文（题干、选项） | `#2C3038` |
| 辅助说明（单位、备注） | `#6B7280` |
| 占位/禁用 | `#9CA3AF` |

### 交互色板

| 元素 | 颜色值 |
|------|--------|
| 确认按钮 / 选中态 | `#2563EB`（Blue 600） |
| 按钮文字 | `#FFFFFF` |
| 错误反馈 | `#DC2626`（Red 600） |
| 正确反馈 | `#16A34A`（Green 600） |

### 卡片样式
- 背景：`#FFFFFF`
- 圆角：`16px`
- 内边距：`20px 24px`
- 阴影：`0 1px 3px rgba(0,0,0,0.04)`（仅悬浮态）
- 边框：无

## 四、通用组件规范（深浅主题一致）

### 顶部导航
```
[ ← ]  已答 0 · 正确率 0%
```
- 高度：`56px`
- 字体：`14px`，辅助色（`#6B7280` / `#8A8F98`）
- 左侧返回按钮，右侧无多余图标

### 题型标识
```
基期与现期 · 求基期量
```
- 字体：`13px`，字重 `500`
- 颜色：主色（`#2563EB` / `#3B82F6`）
- 位置：题目上方，左对齐

### 题目主数字
```
2023年常住人口为 2211.82 万人，同比增长 1%，求基期常住人口。
```
- 数字字号：`28px`，字重 `600`
- 单位字号：`14px`，辅助色

### 选项（选择模式）
- 布局：2×2 等宽网格
- 每个选项：圆角 `12px`，背景使用卡片次级色
- 选中态：边框 `2px solid` 主色，背景不变
- 悬停/按下：透明度微变（无大动效）

### 填空模式（输入框）
```
[ 输入答案（亿元） ]
```
- 高度：`48px`
- 背景：卡片次级色
- 边框：`1px solid` 分割线色（聚焦时变为主色）
- 占位文字：辅助色

### 确认按钮
```
[ 确认 ]
```
- 高度：`48px`
- 圆角：`12px`
- 宽度：100%
- 背景：主色
- 文字：白色，`16px`，字重 `500`

### 反馈区（错误/正确示例）
```
❌ 回答错误
正确答案：22010.67亿元
基期量 = 现期量 ÷ (1 + 增长率) = 20910.14 ÷ 0.95 = 22010.67亿元
```
- 错误：红色文字 + 红色细边框卡片
- 正确：绿色文字 + 绿色细边框卡片
- 底部“下一题”：文字按钮，主色

## 五、主题切换

提供三种选项：
- 浅色（Light）
- 深色（Dark）
- 跟随系统（System）

切换方式：设置页或顶部菜单（无闪烁，通过 CSS 变量即时生效）

## 六、交互微动效

| 操作 | 动效 |
|------|------|
| 按钮点击 | `opacity` 0.15s 降至 0.7 |
| 选项切换 | `border-color` 0.2s ease |
| 反馈出现 | `opacity` 0.25s ease（无位移） |
| 主题切换 | 即时生效，无过渡动画 |

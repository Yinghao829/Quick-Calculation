# 领域引擎 V2 实现计划（选项重构 + 下降 + 年份化 + 填空精度 + 视觉规范）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按用户 ISSUE.md 四条问题 + 三份新文档（OPTION_GENERATOR.md / FILL_IN_QUESTION.md / VISUAL_DESIGN_SCHEME.md）重构出题引擎的选项、增长率、题干措辞、填空精度，并对齐视觉规范。

**Architecture:** 领域层（纯 Kotlin）保持「数据生成 → 答案计算 → 错误模型 → 选项生成 → 解析生成」分离。选项由各题型生成器计算「错误路径干扰项」，交给 OptionGenerator 统一去重/兜底/乱序。增长率池扩充为不规则 + 下降值。题干统一用年份替代「基期/现期」表述。

**Tech Stack:** Kotlin + Jetpack Compose；纯函数领域层 + JUnit 单测；Gradle 8.14.2 / AGP 8.13.2 / Kotlin 2.4.20。

**Spec:**
- `docs/ISSUE.md`（四条问题）
- `docs/OPTION_GENERATOR.md`（选项生成方案）
- `docs/FILL_IN_QUESTION.md`（填空精度方案）
- `docs/VISUAL_DESIGN_SCHEME.md`（视觉方案）
- `docs/QUESTION_GENERATION_ENGINE.md`（既有引擎契约）

## Global Constraints

- 领域层为纯 Kotlin，不依赖 Android；单测在 `app/src/test`，不跑设备。
- 选项数量恒为 4，互不重复，且必含正确答案（现有 `OptionGeneratorTest` 不变量）。
- 正答案题型的干扰项必须 `> 0`（`build_positiveDistractorsForPositiveCorrect` 不变量）。
- `Question.correctAnswer` 语义不变：`%` 类题型存「百分点」（×100），`百分点` 类题型存百分点数值。
- 中间计算保留高精度，仅最终答案按难度 `decimals()`（EASY=0 / MEDIUM=1 / HARD=2）舍入。
- 增长率必须落在 `Topic.growthRange` 内（`sampleRate_staysInTopicGrowthRange` 不变量）。
- 现有子类型标识（`subType`）不变，UI 依赖它们做标签。
- 每次任务末尾跑 `./gradlew testDebugUnitTest`，绿了才提交。

### Task 6–12: 各题型计算错误路径干扰项

> 每个任务同一模式：在生成器内用中间量算 3 个错误路径候选，传给 `OptionGenerator.build(..., distractors = ...)`。公式如下（`dec` 为难度小数位，最终候选由 OptionGenerator 舍入）。

**Task 6: BasePeriodGenerator 干扰项**
- 求基期量（correct = B，给定现期 A、r）：`A*(1-r)`（错误减法）、`A-B`（把增长量当答案）、`A*(1+r)`（乘除颠倒）。
- 求现期量（correct = A，给定基期 B、r）：`B*(1-r)`（符号错）、`B*r`（把增长量当现期）、`B/(1+r)`（乘除颠倒）。

**Task 7: GrowthAmountGenerator 干扰项**
- 求增长量(现期+基期)（correct = A-B）：`B`（基期）、`A`（现期）、`A*r`（现期×增长率）。
- 求增长量(现期+增长率)（correct = A*r/(1+r)）：`A*r`（忘÷(1+r)）、`A`（把现期当增长量）、`A*r/(1-r)`（符号错）。

**Task 8: GrowthRateGenerator 干扰项（答案单位：百分点 ×100）**
- 求增长率(现期+基期)（correct = (A-B)/B*100）：`(A-B)/A*100`（现期做分母）、`A/B*100`（现期÷基期，未减 1）、`B/A*100`（颠倒）。
- 求增长率(增长量+基期)（correct = X/B*100，A=B+X）：`X/A*100`（分母误用现期）、`A/B*100`（现期÷基期）、`B/X*100`（颠倒）。

**Task 9: RatioGenerator 干扰项（答案单位：百分点 ×100）**
- 现期比重（correct = P/Q*100）：`(Q-P)/Q*100`（剩余部分）、`P/(Q-P)*100`（分母取错）、`Q/P*100`（颠倒）。
- 基期比重（correct = (P/Q)(1+b)/(1+a)*100）：`P/Q*100`（现期比重，忘修正）、`(P/Q)(1+a)/(1+b)*100`（a、b 反）、`(P/Q)(1+b)/(1-a)*100`（符号错）。
- 两期比重差（correct = |(P/Q)(a-b)/(1+a)|*100）：`(P/Q)(a-b)*100`（忘÷(1+a)）、`(P/Q)(a-b)/(1+b)*100`（分母用整体）、`(a-b)*100`（忘乘 P/Q）。

**Task 10: AverageGenerator 干扰项**
- 现期平均数（correct = total/count*10000）：`total/count*1000`（单位换算少 ×10）、`count/total*10000`（颠倒）、`total*(1+a)/count*10000`（总量误乘增速）。
- 基期平均数（correct = (total/(1+a))/(count/(1+b))*10000）：`total/count*10000`（现期平均数）、`(total/(1+b))/(count/(1+a))*10000`（a、b 反）、`(total/(1+a))/(count/(1+a))*10000`（两增速同用 a）。

**Task 11: MultipleGenerator 干扰项**
- 现期倍数（correct = A/B）：`(A-B)/B`（多几倍）、`B/A`（颠倒）、`(A+B)/B`（把和当倍数）。
- 基期倍数（correct = (A/(1+a))/(B/(1+b))）：`A/B`（现期倍数）、`(A/(1+b))/(B/(1+a))`（a、b 反）、`(A/(1+a))/(B/(1-a))`（符号错）。

**Task 12: SpecialRateGenerator 干扰项（答案单位：百分点 ×100）**
- 间隔增长率（correct = (r1+r2+r1r2)*100）：`(r1+r2)*100`（直接相加）、`r2*100`（只取第二年）、`(r1+r2+r2*r2)*100`（交叉项误用 r2²）。
- 混合增长率（correct = (B1r1+B2r2)/(B1+B2)*100）：`(r1+r2)/2*100`（简单平均）、`(B1r2+B2r1)/(B1+B2)*100`（r1、r2 反）、`(B1r1+B2r2)/abs(B1-B2)*100`（分母相减）。
